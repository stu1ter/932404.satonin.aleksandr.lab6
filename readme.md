Лабораторная работа №6 по курсу «Введение в Node.js и базовый сервер на Express».  
**Вариант №9: «Каталог книг» (поиск и фильтрация)**

Проект представляет собой веб-приложение, сочетающее в себе бэкенд на **Node.js/Express** и современный фронтенд, превращенный в **PWA (Progressive Web App)** с возможностью установки на устройство и полноценным офлайн-режимом.

---

## 🛠️ Функционал проекта
* **Локальный веб-сервер:** Раздача статических HTML, CSS и JS ресурсов.
* **REST API маршруты:** Реализация роутов `/`, `/about` и `/api/books`.
* **PWA поддержка:** Приложение имеет валидный манифест и может быть установлено на Windows/Android/iOS как самостоятельная программа.
* **Автономность (Офлайн-режим):** Благодаря Service Worker сайт открывается и работает даже при полном отсутствии интернет-соединения.
---

## 🚀 Запуск проекта

### 1. Требования
Убедитесь, что на компьютере установлен **Node.js** (LTS-версия). Проверить установку в консоли:
```bash
node -v
npm -v
```

```bash
git clone 932404.satonin.aleksandr.lab6
cd 932404.satonin.aleksandr.lab6
npm install
node server.js
```

Откройте любой современный браузер и перейдите по адресу: **`http://localhost:3000`**
